小白之问：有了顶级 CPU，为什么还要买显卡？

📌 核心概念板书

  • 疑问：我的 CPU 已经有 8 核 4.5GHz，为什么算 AI 和图像时它慢得像乌龟？
  • 本质：CPU 追求单任务极致极速（低延迟），GPU 追求海量任务一起算（高吞吐）。
  • 芯片晶体管取舍：CPU 把面积留给大脑袋（缓存与控制），GPU 铺满了算术手（ALU）。

🎙️ 讲师详细口播讲稿

很多初学者刚接触高性能计算时，心里都会有一个巨大的疑问：我的电脑已经配了最新款的顶级 CPU，主频高达四点几吉赫兹，平时玩系统极其流畅，为什么一跑大模型或者渲染视频，CPU 就卡得动弹不得，非要我们额外掏几千块钱去买一张独立显卡呢？显卡到底有什么神奇的超能力？今天这一节，我们不背枯燥的教科书，用三分钟彻底搞懂 CPU 与 GPU 的本质区别，打开异构并行计算的大门！

生活大比方：老教授 vs 5000 个小学生

📌 核心概念板书

  • CPU 是大学老教授：精通微积分和奥数，但他只有一个人，做题只能一道道来。
  • GPU 是 5000 个小学生：只会最简单的加减乘除，但 5000 个人同时坐在大礼堂里动笔。
  • 算一千万道加减法：老教授做完要累趴下，5000 个小学生一人一道，几秒钟全班交卷！

🎙️ 讲师详细口播讲稿

为了让大家彻底拥有物理直觉，我们打一个经典的生活大比方。你可以把 CPU 想象成一位顶级大学的老教授，他精通微积分、高等代数，逻辑推导滴水不漏。但老教授只有一个人，如果你让他去解一道复杂的逻辑大题，他两秒钟就能解开。可如果你现在交给他一千万道小学一年级的加法题，老教授就算手速再快，一道一道做下来，也得累得晕过去。那 GPU 是什么呢？GPU 相当于大礼堂里坐着的 5000 个小学生！小学生不会高深的微积分，他们每个人手里拿着一根铅笔，只会做加减乘除。面对这一千万道加法题，老教授发号施令，5000 个小学生每人认领一道，同时动笔！一秒钟做完 5000 道，几秒钟时间，一千万道题全部交卷！这就是为什么在 AI、图形渲染这些纯粹由简单加减乘除组成的数据密集型任务面前，GPU 能够形成对 CPU 几百倍的碾压！

从图形到通用计算：CUDA 到底革了什么命？

📌 核心概念板书

  • 过去：GPU 只是用来给显示器画 3D 游戏的（固定渲染管线）。
  • 痛点：早年想用显卡算数学，必须把数据伪装成三角形和像素颜色，极其痛苦。
  • 2006 年 CUDA 诞生：NVIDIA 彻底打通壁垒，让程序员用 C/C++ 就能直接指挥小学生！

🎙️ 讲师详细口播讲稿

既然显卡算数这么厉害，为什么直到 2006 年大家才大规模用它来算科学计算和人工智能呢？因为在早期，GPU 只是个纯粹的画图工人，硬件被死死固定在画三角形和给像素涂颜色的流程里。那时候聪明的科学家们如果想用显卡算一个矩阵乘法，简直像在演特务电影：他们必须把数字伪装成像素的红绿蓝颜色值，把加减乘除伪装成图形渲染着色器，代码写得极其痛苦，还容易出错。2006 年，NVIDIA 掌门人黄仁勋做出了一个价值百亿美元的豪赌，正式推出了 CUDA 架构！CUDA 的出现彻底砸碎了图形画图的铁笼子，它直接给开发者提供了熟悉的 C/C++ 编程接口，让我们终于能够像写普通程序一样，直接用代码指挥显卡里成千上万个核心进行通用数学计算！这一场革命，直接奠定了今天深度学习和大模型繁荣的基石。

一句话记住本质与小白课后自测

📌 核心概念板书

  • 极简口诀：复杂串行找老教授(CPU)，海量简单活找小学生(GPU)！
  • 核心指标：CPU 专攻低延迟（单任务极快），GPU 专攻高吞吐（总数据量极大）。
  • 小白自测：如果一个任务只有 5 行代码但包含 10 个层层嵌套的 if-else，该用 CPU 还是 GPU？

🎙️ 讲师详细口播讲稿

学完这一节，大家在脑海中只需要牢牢印刻两句话。第一句心智口诀：复杂串行找老教授 CPU，海量并发简单活找小学生 GPU！第二句微架构真相：CPU 把晶体管用来做大缓存和复杂预测以降低延迟，GPU 把晶体管全部铺成绿色计算核心以拉满吞吐。最后留给大家一个 5 秒钟就能想出答案的小自测题：如果你的程序只有区区 5 行代码，但是里面包含 10 个层层嵌套的 if-else 复杂条件跳转，后一步完全依赖前一步的结果，你觉得这时候应该派 CPU 上场，还是派 GPU 上场呢？答案显而易见：这种需要高超逻辑推导和快速反应的任务，老教授 CPU 两秒钟就能搞定，派小学生 GPU 只能在原地打架！带着这种清醒的认知，下节课我们将带大家认识 CPU 和 GPU 是如何在物理总线上配合干活的！
